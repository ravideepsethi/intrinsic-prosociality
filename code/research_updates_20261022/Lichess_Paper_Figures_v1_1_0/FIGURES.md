# Manuscript figures

The October 8 manuscript's six statistical figures can be reproduced from
checked aggregate files in this repository:

```bash
bash code/paper_figures/RUN_FIGURES.command
```

This exports vector PDF/SVG and 600-dpi PNG figures in one consistent
publication style. Initial dependency setup usually takes 2-5 minutes;
rendering takes under one minute. No model is re-estimated.

Read [the figure documentation](docs/paper_figures.md) for the Mac setup,
manuscript mapping, source and sample qualifications, and maintenance.
[Reference figures](results/paper_figures_v110/figures/) and a
[six-page review PDF](results/paper_figures_v110/figure_review.pdf) are included.

The original September 11 README and its release manifest remain unchanged.
This figure build has its own input manifest and validation record.
