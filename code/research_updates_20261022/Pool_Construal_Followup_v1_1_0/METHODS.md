# Follow-up methods and decision rules

## Frozen comparison

Retain v1.0.0 feature basis, chronology, five-minute receipt separation rule, persistent type structure, likelihood weights, ridge coefficient and complexity selected within the first year. All four selected switching families use three persistent support points. No second-year outcome selects complexity or the primary numerical bound. Evaluation accounts remain disjoint from the original 100,000-account pilot and from development accounts.

The new likelihood uses log-domain forward/backward recursions and exact log predictive scores. It integrates a persistent type once per account and filters states and types forward before scoring each current outcome. It avoids probability floors when wider bounds produce extreme logits. The original objective and held-out losses must reproduce within 1e-7 before any refit is interpreted.

Bounds 7, 12 and 20 are numerical sensitivity settings. The first matches v1.0.0. The lower reference intercept is bounded by `[-max(16,2w),1]`, its softplus gap parameter by `[-max(8,w),w]`, and remaining free parameters by `[-w,w]`. At least half the nominal starts are dispersed (at least two); extra warm starts never displace those starts. Warm starts include prior selected models, the previous bound's solution and valid restricted embeddings. Choose the lowest objective among converged starts, or the lowest objective if none converge; explicitly report when a nonconverged start has a better objective. L-BFGS-B success, projected gradients, active bounds and objective dispersion are reported separately. Numerical convergence is not global optimality.

Primary score gain is the candidate minus baseline mean log predictive score, at fixed width 20 by default. Positive favors the candidate. Conditional score SEs cluster by evaluation account; equal-account gains are also shown. The four primary comparisons have Holm adjustment. A null unrestricted improvement is not an equivalence test.

## Refit uncertainty

Each replication independently multinomial-resamples the full retained training accounts and full retained evaluation accounts. Training weights enter the likelihood; evaluation weights enter score aggregation. All four families are refit at fixed complexity and width, with at least four nominal starts plus any necessary extra warm starts. The resampling stream matches v1.0.0. Draw 6 is first reproduced using its verified original fit attempts and then reoptimized at the three bounds.

Use 120 replications by default. Report the SD of converged paired score gains, positive-draw count, converged-draw count and boundary-draw count. Do not interpret positive-draw proportions as bootstrap p-values. Percentile intervals are withheld below 100 converged paired refits. Selective nonconvergence can still compromise intervals; inspect failure counts. This is a frozen-complexity account bootstrap, not a bootstrap over complexity selection, prior specification search, calendar shocks or network dependence.

## Recovery at the actual information scale

Use every retained development account in year one: 19,939 accounts, 188,008 opportunities. Preserve its observed covariates and receipt histories. Use independently simulated full evaluation histories, updating on their simulated first-year outcomes and scoring simulated second-year choices. The real second-year sample has 344,602 opportunities and 4,254 grants, but training identification is tied to 2,477 grants, not the larger evaluation grant count.

Generating parameters are the widest-bound gate, willingness and unrestricted fits, plus a willingness case with a 0.03-logit reference emission gap. In each scenario adjust only the common reference intercept to make expected training grants equal 2,477, given the fixed design. Draw each account's persistent type once, then simulate its state chain and choices. The calibration target does not force realized counts; those are reported for every replicate. Each competing fit gets the same frozen empirical-model warm starts plus dispersed starts, not the calibrated generating vector.

Twenty replications per scenario are the starting budget. Report paired held-out selection frequencies with Wilson intervals quantifying Monte Carlo uncertainty, and bias/RMSE for the reference gap, receipt entry and staying coefficients, their difference and reference transition probability changes. Only all-model-converged replications enter pairwise selection summaries; report that denominator. Cross-family parameter discrepancies describe parameterization differences as well as estimation error. Near-collapse is deliberately difficult. This conditional-design simulation does not regenerate endogenous opportunities or receipt histories and does not establish moral-state identification.

## Receipt transitions

Report tau-entry (receipt effect on the logit of entering state 1 from state 0), tau-stay (effect on remaining in state 1), and tau-stay minus tau-entry. State 1 has a higher emission intercept at the fixed reference configuration; emissions can cross elsewhere. Also report reference probability changes averaged over persistent-type weights.

For well-separated evaluation receipt-risk intervals, hold the filtered pre-interval type/state distribution and all other current covariates fixed. Change the receipt input from zero to one. The grant forecast difference decomposes exactly into a previous-state-0 contribution and a previous-state-1 contribution, each multiplied by that type's current emission difference. Report both contributions and the corresponding changes in next-state probability. Bootstrap these summaries with the same refits and evaluation account weights. These are model-input predictive contrasts; receipt is not randomized in the likelihood. Hard state classifications are not used.

## Opportunity and activity outcomes

Retain the reviewed 2,682,330-exposure, complete-90-day IV cohort, instrument, controls, fixed effects and shared-account OR exposure-date CR0 covariance. Reproduce original pooled next-grant and lost-position count coefficients and SEs within 1e-7. Retain first-stage diagnostics and null-moment Anderson–Rubin sets from the reviewed implementation. Count outcome estimates are in events per exposure; `next_grant_90` is in percentage points. Existing AR sets carry percentage-point scaling and must be divided by 100 for count outcomes, as explicitly labelled.

All future main-panel games start strictly after the anchor and have a strictly later recorded last move no later than day 90. Exclude the original game and original opponent. Define two roles independently: recipient later chooser, or recipient later disconnected player. Board categories are evaluated from the disconnected player's side: lost is <= -300 cp, competitive is >= -100 cp, all includes intermediate positions. Thus the actor whose position is lost differs between roles. Draw plus claim equals the chooser lost-position count exactly. Windows are days 1–7, 8–30 and 31–90, inherited from cumulative horizons, with day 1 including all strictly positive times through 24 hours.

The main panel is action-resolved. Its counts can move because of play, positions, disconnections, grants/claims or eligibility. They are post-treatment outcomes, not controls. Do not divide IV grant effects by opportunity effects or condition the IV sample on subsequent opportunities.

The broader API diagnostic uses only completed canonical Stage04 sources or the pinned historical curated selector, never a recursively combined file pile. Monthly row counts, unique IDs, creation month and alias agreement are checked. A month is unusable if timing errors exceed 0.1% or missing/identical participants exceed 2%; counts exclude invalid individual rows. Restrict to rated standard real-time timeout/outoftime candidates. Normalized usernames are bridged to the original exposure participants with a one-to-one ID check. Both recipient roles count, since a validated who-disconnected field and board evaluation are not available for all candidates. This is not a physical-disconnection census. Only exposures with all months covering their complete 90-day window present enter API IV estimates; reestimate selected main-panel outcomes and the original next-grant outcome on the same subset.

The chronology diagnostic scans all 144 files in the frozen rating replay inventory. File size, row and row-group counts must match; current full content hashes are recorded (historical full content digests are unavailable). A deterministic outcome-blind sample of 10,000 exposure games must match creation timestamps and both numeric participants. Count future game starts in either color, excluding the original opponent. This measures activity within that chronology corpus; its clock and coverage differ from main-panel recorded-end outcomes. Missing chronology files suppress that broader estimate rather than becoming zeros.

Holm adjustment is within three fixed follow-up families: 25 reviewed-cohort endpoints (18 role/category counts, three lost-position grant counts, three claim counts and one next-grant bridge), three chronology endpoints, and 16 API-covered-subset endpoints (six API counts and ten same-subset reference outcomes). Unavailable endpoints remain in family size. These follow-up families were chosen after the original results were inspected; they are not preregistered confirmation. Broader-source failures are reported without suppressing completed model work.

An effect of receipt on later activity can be a treatment-mediated response. It does not automatically violate instrument exclusion. It can change which opportunities enter an action-conditional analysis, so separating the counts is necessary before advancing a mechanism claim.
