It is historical/planning guidance and not a guaranteed elapsed time. Completed source versions are associated with their returned result receipts.

## Known runtime setup fix for Wave 2B2B1

The preserved v1.0.0 C6/C10 package needs its private state directory to exist before its first Parquet write. The later completed report is authoritative. On the original project root, initialize the directory before the documented launcher:

```bash
/bin/mkdir -p "/Volumes/XT_Pro/lichess_kindness/derived/replication/pool_main_reanalysis_v100_PRIVATE/wave2b2b1/campaign_state/C6_C10"
```

Directory setup takes **under one second**; the package states **35–75 minutes** for the full analysis. If using a different `--private-base`, create `campaign_state/C6_C10` below that base. The original source bytes and package hash are retained.
